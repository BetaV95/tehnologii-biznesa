# Технологии Бизнеса — сайт

Первый прототип лендинга на Next.js.

## Что нужно установить

1. Node.js LTS: https://nodejs.org/
2. Visual Studio Code: https://code.visualstudio.com/

## Запуск

Откройте терминал в папке проекта и выполните:

```bash
npm install
npm run dev
```

Затем откройте адрес, который покажет Next.js, обычно:

http://localhost:3000

## Где менять сайт

Главная страница:
`app/page.tsx`

Стили:
`app/globals.css`

SEO и метаданные:
`app/layout.tsx`

Пока в проекте используются заглушки для телефона, email, цен, клиентов, кейсов и отзывов.
